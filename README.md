(RU)

Для запуска скрипта требуются все файлы, расположенные по папкам. Используемые библиотеки: TKinter, Enum, math. Запускать только файл main.py.

Делать эту песочницу сразу было решено делать на TKinter. PyGame был отброшен из-за его излишеств и ориентации на Aurora 4x, где игра представляет из себя переключение между таблицами.

(EN)

To run the script, you need all the files in the folders. The libraries used are TKinter, Enum, and math. Run only the main.py file.

It was decided to use TKinter for this sandbox. PyGame was discarded due to its excesses and focus on Aurora 4x, where the game involves switching between tables.
